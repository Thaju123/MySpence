# MySpence

Simple local expense tracker. Data stays in your browser’s **localStorage** — no account, no install.

## Run

Open `index.html` in your browser, or from this folder:

```bash
start index.html
```

## Features

- Add daily expenses (amount, category, note, date)
- Today & this-week totals
- Recent list with delete
- Analytics: last 7 days, category breakdown, top-spend insight
